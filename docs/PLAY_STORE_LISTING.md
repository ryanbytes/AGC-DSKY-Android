## Full description

AGC DSKY is an offline historical Apollo Guidance Computer / DSKY simulator for Android.

The app runs the real yaAGC WebAssembly core with the Apollo 11 Command Module Comanche 055 guidance rope and presents a Block II-style DSKY interface driven by AGC channels and relays.

Features include:

- Real yaAGC execution with pinned Comanche 055.
- Apollo Block II-style 19-key DSKY controls and electroluminescent display.
- AGC relay/channel-driven display state, including COMP ACTY.
- Phone motion-sensor input for simulated ICDU and PIPA paths.
- Camera-based command-module sextant interface with MARK and MARK REJECT.
- Apollo navigation-star helper using local astronomical calculations.
- AGC state save/restore and diagnostics.
- Synthetic relay-click audio.
- Android DreamService clock/screensaver.
- Resizable EL-only home-screen widget.
- No Android INTERNET permission.

Camera, location, and motion-sensor inputs are processed locally for simulator features. The app does not include advertising, analytics, user accounts, cloud synchronization, or a developer-operated backend.

AGC DSKY is an independent historical/technical simulator. It is not affiliated with, sponsored by, approved by, or endorsed by NASA or the United States Government.

Source code, GPLv2 license information, third-party notices, and privacy information are available in the public project repository and in the app under LEGAL / SOURCE.
