PRIVACY POLICY — AGC DSKY WEB APP (PWA)
Effective date: September 10, 2026

AGC DSKY is an independent historical Apollo Guidance Computer / DSKY simulator.

DATA ACCESSED BY SIMULATOR FEATURES
- Camera: may be used for a live sextant/optics view when enabled and permitted by the browser.
- Approximate or precise location: may be used for local astronomical calculations such as horizon/navigation-star assistance and local sunrise/sunset brightness control when enabled and permitted by the browser.
- Motion and orientation sensor data: may be used for simulated spacecraft/optics input paths when enabled and permitted by the browser.
- Ambient light sensor: when the browser exposes it, local illuminance readings may be used only on-device to adjust DSKY display brightness. Ambient-light readings are not sent to the analytics service.
- App state and preferences: simulator state, settings, brightness mode, cached solar coordinates, and related configuration may be stored locally so the app can restore its state.

CLOUDFLARE WEB ANALYTICS
The deployed PWA may use Cloudflare Web Analytics to measure aggregate page views, visitors, referring pages, browser/device information, and web performance. The Cloudflare Web Analytics JavaScript beacon is loaded from Cloudflare and sends Web Analytics measurements to Cloudflare.

AGC DSKY does not create or store a custom installation identifier for Web Analytics. It does not send custom launch or installation events, AGC key presses, simulator state, camera images, ambient-light readings, motion/orientation sensor readings, or the location used by simulator features to the analytics service.

Cloudflare describes Web Analytics as privacy-first analytics and states that it does not collect or use visitors' personal data or track individual end users across Cloudflare customers' Internet properties. The application does not use advertising analytics and does not sell analytics data.

OFFLINE USE
After the PWA has cached its required files, the AGC simulator can run offline. Cached coordinates can continue to provide sunrise/sunset dimming calculations while offline. Cloudflare Web Analytics cannot report measurements while the browser is offline; analytics failure does not prevent simulator operation.

LOCAL STORAGE AND DELETION
Simulator state, settings, cached solar coordinates, and related preferences may remain in browser storage until cleared by the user. Ambient-light readings are kept only in memory while the app runs. AGC DSKY does not place a custom analytics identifier in local storage.

CHILDREN
The app is a general historical/technical simulator and is not specifically directed to children. It does not knowingly collect names, contact information, precise location, or other identifying profile information from children or other users through an AGC DSKY-operated analytics database.
